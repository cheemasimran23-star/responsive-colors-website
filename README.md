# Responsive Colors Assignment

This project keeps the supplied `index.html` unchanged and only adds the two required media queries to `css/style.css`.

## Important: original images
The uploaded starter files did not include the original `images` folder. The HTML references these original image files:
- `images/Red.jpeg`
- `images/Orange.png`
- `images/Yellow.png`
- `images/Green.png`
- `images/Blue.png`
- `images/Indigo.jpeg`
- `images/Purple.png`
- `images/Pink.jpeg`
- `images/White.png`

Copy the original `images` folder from the GitHub starter project into this folder (next to `index.html`) before opening the website. No replacement images have been substituted.

## Required responsive rules
- At 772px: div width 45vw, display inline-block, image max-height 30vh.
- At 998px: div width 30vw.

Open `index.html` in a browser and test at widths below 772px, between 772px and 997px, and at 998px or wider.
